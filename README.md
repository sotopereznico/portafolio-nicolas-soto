# Portafolio Profesional - Nicolás Soto Pérez

Este repositorio contiene el código fuente de mi portafolio web personal, diseñado para presentar mi perfil técnico, trayectoria y proyectos destacados como Desarrollador Full Stack Java Trainee.

## Características del Proyecto

- **Diseño Single Page (SPA):** Navegación fluida en una sola página con efecto de desplazamiento suave (smooth scroll) desde el menú de navegación.
- **Interfaz Responsiva:** Diseño completamente adaptable a diferentes tamaños de pantalla, desde teléfonos móviles hasta monitores de escritorio.
- **Estilo Visual:** Tema oscuro sobrio con un fondo de degradado diagonal azul y paleta de colores en tonos madera.
- **Exhibición Interactiva de Proyectos:** Layout en formato zig-zag que incluye integración de iframes de Google Drive con reproducción automática de videos al pasar el cursor (hover) y enlaces directos a los códigos fuente.

## Tecnologías Utilizadas

- **HTML5:** Estructuración semántica del contenido.
- **CSS3:** Estilos personalizados, uso de variables de color (`:root`), Flexbox/Grid para el diseño estructurado y Media Queries para la responsividad.
- **JavaScript (Vanilla):** Lógica pura para la interactividad del DOM, incluyendo la manipulación de URLs en iframes y navegación suave.

## Estructura del Repositorio

- `index.html`: Estructura principal de la página y textos descriptivos.
- `style.css`: Hoja de estilos principal.
- `script.js`: Archivo con la lógica de interactividad y animaciones.
- `README.md`: Documentación e información general de este repositorio.

## Despliegue

Este proyecto está diseñado y optimizado para ser desplegado de manera estática a través de **GitHub Pages**.

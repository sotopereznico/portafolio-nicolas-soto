Proyectos Relevantes

A continuación, presento una selección de los proyectos técnicos más significativos desarrollados durante mi formación práctica.

Sistema de Gestión Educativa (SpringEduManager)

Categoría: Aplicación Web Enterprise (Full Stack)

Descripción: Plataforma web integral diseñada para la gestión de estudiantes, cursos y evaluaciones en instituciones educativas.

Desafío Principal: Implementar una arquitectura limpia en capas con autenticación segura y persistencia de datos relacionales eficiente.

Solución Aplicada: Desarrollo utilizando Spring Boot con arquitectura MVC, gestión de acceso con Spring Security y mapeo objeto-relacional mediante Spring Data JPA.

Tecnologías: Java, Spring Boot, Spring Security, JPA, HTML5/CSS3, SQL.

Biblioteca Digital UNTEC

Categoría: Aplicación Web Dinámica Java EE

Descripción: Sistema de administración para catálogos de libros, registro de usuarios y préstamo de material bibliográfico.

Desafío Principal: Coordinar la interacción cliente-servidor mediante servlets sin frameworks de nivel superior.

Solución Aplicada: Arquitectura basada en patrón MVC con Servlets, páginas JSP dinámicas y capa DAO para el manejo de la base de datos.

Tecnologías: Java EE, Servlets, JSP, SQL, Apache Tomcat, Bootstrap.

Alke Wallet (Billetera Digital)

Categoría: Diseño Web Front-end

Descripción: Interfaz funcional para una billetera virtual que permite gestionar fondos y transferencias.

Desafío Principal: Diseñar una interfaz clara centrada en la experiencia de usuario.

Solución Aplicada: Maquetación de vistas interactivas y adaptables a dispositivos móviles.

Tecnologías: HTML5, CSS3, JavaScript, Bootstrap.

SmartTask (Gestor de Tareas en Consola)

Categoría: Aplicación Java Core & POO

Descripción: Herramienta de consola para la gestión de tareas personales (creación, listado, marcado de completadas y eliminación).

Desafío Principal: Aplicar principios sólidos de programación orientada a objetos y asegurar la estabilidad del software mediante pruebas automatizadas.

Solución Aplicada: Uso de principios SOLID, estructuras de datos en memoria y cobertura de pruebas unitarias exhaustivas.

Tecnologías: Java SE, Programación Orientada a Objetos, JUnit 5.
